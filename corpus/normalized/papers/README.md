**Purpose:** cleaned, chunked text derived from `corpus/raw/papers/`.

**Allowed:** chunks with `lineage` → a `raw/papers/` `doc_id`, **Tier B**
unchanged, manifest provenance (authors/venue/year preserved).

tier upgrades.
