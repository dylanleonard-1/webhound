# `corpus/raw/papers/` — Research & academic papers (Tier B)

**Purpose:** as-fetched original research — academic papers, vendor research,
threat reports — that explains *why* a detection technique works.

**Allowed:** papers/reports whose license/ToS permits storage (or open-access
preprints), with a provenance record (authors, venue, year, DOI/URL).

**Prohibited:** paywalled content stored in violation of terms, secrets/PII,
mis-attributed copies.

**Source authority:** **Tier B** — original research. With Tier A it outranks
Tier C/D/E. Useful to ground detection-engineering and malware analysis.

**Ingestion expectations:** Phase 5 only; **empty now**.

**Retention expectations:** `permanent`/`long` (research is durable); store the
canonical version + hash.
