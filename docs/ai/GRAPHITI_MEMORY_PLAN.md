# Graphiti Memory Plan

Phase 8A plan for integrating Graphiti episodic memory into WebHound AI Brain.

## What Graphiti Does

Graphiti provides bi-temporal episodic memory for AI agents. It stores facts as
time-indexed episodes with validity windows, enabling:
- "What was the WADE confidence threshold when this decision was made?"
- "Has the Cloudflare WAF behavior changed since Phase 6C?"
- "What is the current FP suppression policy for GreyNoise IPs?"

Graphiti is purpose-built for AI agent memory with graph-backed storage.

## Memory Types (10)

| Type | Purpose |
|------|---------|
| `engineering_decision` | Architectural choices and their rationale |
| `scanner_behavior` | Documented scanner engine behaviors and quirks |
| `false_positive_pattern` | Known FP patterns WADE should suppress |
| `provider_behavior` | Provider-specific response patterns |
| `threat_intel_rule` | TI feed behavior rules |
| `taxonomy_rule` | CWE/OWASP/severity classification rules |
| `WADE_policy` | WADE operational policies and thresholds |
| `retrieval_decision` | Choices about retrieval configuration |
| `phase_status` | Phase completion milestones and outcomes |
| `benchmark_result` | Evaluation benchmark scores |

## Seeding from Generated Data

```python
import json
import asyncio
from graphiti_core import Graphiti

async def seed():
    g = Graphiti("bolt://localhost:7687", "neo4j", "password")
    await g.build_indices_and_constraints()

    with open("corpus/exports/graphiti_seeds.json") as f:
        data = json.load(f)

    for seed in data["seeds"]:
        await g.add_episode(
            name=seed["name"],
            episode_body=seed["content"],
            source_description=seed["source"],
            reference_time=seed["valid_at"],
        )
    print(f"Seeded {len(data['seeds'])} memories")

asyncio.run(seed())
```

## WADE Integration Pattern

When WADE evaluates a finding:

```python
# Retrieve relevant memories
results = await graphiti.search(
    f"false positive patterns for {provider} {finding_type}",
    num_results=5
)

# Use memories to adjust confidence
for r in results:
    if r.episode_type == "false_positive_pattern":
        confidence -= 0.2
    elif r.episode_type == "WADE_policy":
        apply_policy(r.content)
```

## Safety Constraints

- **No customer data**: Only ingest from this seed file and the corpus — never live scan results or PII
- **No credentials**: The Neo4j password above is a local dev example only
- **No external APIs**: Graphiti graph storage is local (Neo4j) only
- **No cloud sync**: Graph data stays on-premises
