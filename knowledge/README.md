# knowledge/ — Curated Knowledge Library

**Purpose:** Human-reviewed, curated WebHound knowledge: engine knowledge, false-positive lessons, detection-engineering methodology, JS-malware reference, provider remediation pointers, and playbooks. This is the *curated* layer; the *evidence* layer is `corpus/`.

**What belongs here:** Curated notes (pointer-first), false-positive lessons, methodology, link+summarize provider/OWASP references, playbooks.

**What does NOT belong:** Raw evidence (use corpus/), secrets, customer data, mirrored full vendor docs.

**Authority:** trusted_local + cited Tier-A/B; community is workflow-only, never security authority.

**Review status:** mixed: some seeded (curated), most future-placeholder

**Content type:** curated
