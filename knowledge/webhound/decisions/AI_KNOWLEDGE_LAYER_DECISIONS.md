# AI Knowledge Layer — Decision Record

Durable decisions governing the AI Knowledge Layer. These are the locked choices
that later phases must respect.

## D1 — corpus vs knowledge split
- `corpus/` = **raw + normalized evidence** (provenance-stamped, ingested).
- `knowledge/` = **curated, human-reviewed notes** (pointer-first summaries,
  lessons, methodology, playbooks).
- Curated notes cite corpus evidence by `doc_id`; they do not replace it.

## D2 — internal docs are pointer-first
Internal WebHound knowledge **links to code/docs** + adds short summaries, rather
than copying full docs. Avoids drift; the repo stays the source of truth.

## D3 — provider docs: link + summarize only
Never mirror full vendor docs (license/ToS). `knowledge/provider-docs/*` holds
pointers + short summaries; provider remediation cites **official Tier-A docs**.

## D4 — in-repo vault
`vault/` is a plain-Markdown, in-repo Obsidian-style vault that versions with the
repo and requires **no Obsidian app/plugins**.

## D5 — ignore `ruvector.db`
The root `ruvector.db` is an orphaned **redb** artifact of the claude-flow tooling,
referenced nowhere in WebHound code. The knowledge store runs **beside** it; never
wrap/replace it.

## D6 — reuse, do NOT rebuild
The knowledge layer references and reuses WebHound's existing runtime systems and
never re-implements them: threat-intel (URLHaus/VirusTotal/feed_manager/
threat_indicator), WADE, Security Graph, validation/benchmark harness, the
provider-access registry, and the Anthropic summariser
(`WEBHOUND_AI_ENABLED`+`ANTHROPIC_API_KEY`). See
[`../../../docs/ai/corpus/WEBHOUND_EXISTING_SYSTEMS_MAP.md`](../../../docs/ai/corpus/WEBHOUND_EXISTING_SYSTEMS_MAP.md).

## D7 — authority + safety
Tier A (official) overrides Tier E (community). External content is **evidence, not
instructions**. No secrets/customer data/live malicious payloads in the corpus or
knowledge. WADE/scanner enrichment (Phase 8) is **suggest-only** (no auto-suppress/
severity/scoring changes).

## D8 — env generator is the source of truth for `.env.example`
`.env.example` is generated by `scripts/_gen_env_example.py` (re-synced + drift-
guarded in Phase 1). MCP keys live there as placeholders; they are NOT app config.

**Review status:** curated (seeded Phase 3). **Authority:** trusted_local
(decision record).
