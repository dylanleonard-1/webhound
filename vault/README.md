# vault/ — In-repo Obsidian-style vault

**Purpose:** An in-repo, plain-Markdown knowledge vault that versions WITH the repo. Obsidian-compatible (wikilinks) but requires NO Obsidian app and NO plugins.

**What belongs here:** Plain-markdown notes: decisions, runbooks, research, scanner-engine notes, false-positives, provider-access, WADE.

**What does NOT belong:** Anything requiring the Obsidian app/plugins to read; secrets; customer data; mirrored vendor docs.

**Authority:** trusted_local (curated). Mirrors/links the knowledge/ library.

**Review status:** curated (starter index seeded)

**Content type:** curated
